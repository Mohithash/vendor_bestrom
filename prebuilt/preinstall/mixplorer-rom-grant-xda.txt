MiXplorer: the author's permission to preinstall it in a ROM
============================================================

This file exists so the permission BestROM relies on does not live only in a
third party's bug tracker. It records what was read, where, and when.

--------------

post #6 by HootanParsa (the author), permalink

    https://forum.xda-developers.com/showpost.php?p=23374610&postcount=6

which today redirects to

Read at that URL on 2026-09-07 and confirmed to carry exactly that text.

What BestROM does with it
-------------------------

Both revisions grant the same two things and withhold the same one:

* preinstalling the author's own APK in a ROM is allowed;
* modifying it, or shipping it under a different signature, is not.

So `MiXplorer.apk` is a plain `PRODUCT_COPY_FILES` entry, copied byte for byte,
never repacked and never re-signed, and release signing is told to skip it
(see README.md, "Release signing").

The 2015 revision adds a request the current wording drops: put the app in
`/data`, not `/system`, so users can update it. BestROM does that - the APK
sits in `/product/etc/bestrom/preinstall/` as data, and `BestromPreinstaller`
installs it on first boot as an ordinary user app in `/data`, which the user can
update from the author's own channel or uninstall outright. It is not a system
app.
